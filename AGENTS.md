# AGENTS.md

Навчальна копія публічного сайту Фундації Лятошинського: знайомить із життям і творчістю Бориса Лятошинського, архівними матеріалами, дослідженнями, новинами та способами підтримати фундацію. Застосунок на Next.js і TypeScript; тексти українською та англійською, основна мова — українська (`uk`). Дані беруться з in-memory MongoDB, яку скрипт піднімає разом із `npm run dev`.

## Сторінки

Маршрути живуть у `app/[lang]/`. Локаль стоїть у префіксі URL (`/uk/...`, `/en/...`); без префікса відкривається `uk`.

| Шлях | Бізнес-призначення |
| --- | --- |
| `/` | Головна: спадщина композитора, коротко про фундацію, події, новини, заклик до співпраці |
| `/about-us` | Про фундацію: місія, цілі, засновники, чим займається організація |
| `/biography` | Життєпис Бориса Лятошинського |
| `/artistry` | Творчість: огляд і каталог музичних творів |
| `/research` | Дослідження та наукові роботи |
| `/archive` | Архів: перелік фондів (документи, листи, афіші, рукописи) |
| `/archive/[fund]` | Справи одного архівного фонду |
| `/archive/[fund]/[case]` | Картка архівної справи: опис, склад, навігація документами |
| `/news` | Новини, події та згадки в медіа |
| `/cooperation` | Співпраця для партнерів, благодійників і меценатів |
| `/support-us` | Підтримка фундації: внески, варіанти допомоги, відповіді на питання |
| `/war-in-ukraine` | Діяльність фундації під час війни в Україні |
| `/contacts` | Контакти і форма запиту |
| `/privacy-policy` | Політика конфіденційності |
| `/terms` | Умови користування сайтом |

## Конвенції

- Код пишеться на TypeScript.
- Експортуйте іменовані функції та компоненти. `export default` не використовуйте, окрім файлів маршрутів Next.js (`page.tsx`, `layout.tsx`), де це вимагає фреймворк.
- Основна мова інтерфейсу — українська (`uk`). Англійська (`en`) — друга локаль. Тексти лежать у `i18n/messages/uk.json` та `i18n/messages/en.json`.

## Навчальний репозиторій

Це шаблон для воркшопу spec-driven BA, а не прод-копія. Окрема MongoDB не потрібна: при кожному запуску створюється in-memory база, наповнюється демо-даними і скидається, коли процес зупиняється. Зміни в даних між запусками не зберігаються.
